# Lampa Hub

One Lampa plugin store that merges lampaplugins, k03mad, skaztv, bylampa and lampaguide, dedupes by normalized URL, auto-discovers plugins on GitHub, and keeps a per-plugin history (name, version, date, description, sources, install events).

- `build/build.py` — collects all sources, dedupes, probes URLs, GitHub discovery, bakes `dist/lampa-hub.js` (`--no-github`, `--no-probe`).
- `plugin/lampa-hub.src.js` — client template (`/*__SEED__*/null` is replaced by the catalog).
- `dist/lampa-hub.js` — the plugin to add in Lampa: `https://sanprojects.github.io/lampa-hub/lampa-hub.js` (rebuilt and deployed to Pages by `.github/workflows/build.yml` every 6 hours).
- `dist/catalog.json` — merged catalog.

UI: the hub opens as a page styled like Lampa's official "Расширения" — rows of store cards (avatar, author, name, description, date, status badges) per category, plus rows for installed, new/updated, history and popular plugins. The top row has actions: search, categories, refresh catalog, add by URL, sources, settings. Select a card for install / disable / remove / copy URL; the dialog closes at once and the card (badge, check mark) updates in place. Plugins installed through a CUB account carry the `CUB` tag like in Lampa's own list and, as there, can only be enabled/disabled (removal is on cub.best). Each card shows a live status like Lampa's own page (the script is downloaded when the card appears, cached 3 h): `200 Рабочий` if it mentions `Lampa.`, `500 Плагин не подтверждён` otherwise, `404 Ошибка` if it cannot be loaded; a red `!` means Lampa itself failed to load an installed plugin. Card pictures: the store's own image first, otherwise a screenshot from https://tv-ch.ru/lampa-interface/ (matched by plugin URL at build time), otherwise the GitHub avatar / letter.

Catalog enrichment (build time, `build/build.py`): the source repo on GitHub is resolved from raw/jsDelivr/github.io URLs, and for third-party hosted plugins found by code search (`--no-search` skips it); stars, forks, license, archived flag, last push, repo and owner-account age, topics and the README picture come from the GitHub API; plugins found on GitHub are put into real categories from their name, description and topics. Every plugin gets a domain (shown with its favicon), a `trusted` flag (present in lampaplugins / skaztv / k03mad / bylampa / lampaguide) and a static code scan (`ok` / `warn` / `risk`: miners, eval, obfuscation, cookie/credential access, beacons, IP URLs, plain http) — a heuristic, not a guarantee. Sorting: trusted first, then GitHub stars, last update, owner account age. In the plugin dialog GitHub plugins show the README as plain text (never HTML) and the others show the extended description.

Run: `python3 -I build/build.py`. Note: skaztv.online was unreachable at build time, so its seed comes from a Wayback snapshot; the plugin re-fetches the live list on the device.
